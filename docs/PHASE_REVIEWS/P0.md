## Remaining risks

- Linux/macOS compatibility is by design (Node built-ins only, no shell-specific code) but was **not executed** on those OSes in P0; first CI run (P9) or a Linux shell should confirm.
- Evidence validation is structural: the CLI verifies that cited paths exist, but cannot verify that a quoted `exit=0` really happened. Honesty still relies on the agent following `CLAUDE.md`.
- Node 22 type stripping is flagged experimental (warning suppressed). Upgrading Node or npm later may allow Vitest; changing test tools needs a new ADR.
- The task inventory depends on the roadmap's Markdown format; reformatting headings or task lines will make `check` fail (intended detection, but it couples the CLI to the document layout).
- Stale-lock reclaim is time-based (30 s). Adequate for a single local user; not designed for concurrent multi-agent writers.
- Nothing is committed yet; all P0 work is untracked in Git until the owner commits.
- No `build` script yet (no TypeScript source to compile); planned when `src/` appears.
- Claude Code hooks were not added (optional; deferred to P8-T06 per roadmap).
